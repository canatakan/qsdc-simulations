# QSDC Simulations

Independent QSDC protocol simulators organized by the paper reference.

## Simulators

- `srikara/`: CV QSDC Gaussian-states simulator with analytic and Strawberry Fields backends.

  > Reference: S. Srikara, K. Thapliyal, and A. Pathak, Continuou variable direct secure quantum communication using gaussian states, Quantum Inf. Process. 19, 1 (2020).
